# Suvekshya Jha — Portfolio

A dark, tech-inspired personal portfolio for Suvekshya Jha, showcasing work in frontend development, AI/ML, engineering, and multidisciplinary art.

## Overview

This portfolio presents:

- Personal introduction and professional role
- Skills and technologies
- Featured AI/ML projects
- GitHub links for project repositories
- Contact information
- Downloadable CV
- Responsive cyberpunk-inspired visual design
- Animated role text in the hero section

## Features

- Dark grid-based interface
- Pink neon accent theme
- Responsive layout for desktop, tablet, and mobile
- Smooth navigation between sections
- Animated typing role text
- Featured project cards
- Direct GitHub repository links
- Downloadable CV
- Contact form using the visitor's email application
- Social links for GitHub and LinkedIn

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Vite
- Google Fonts
- SVG icons
- Responsive CSS
- Optional Three.js effects
